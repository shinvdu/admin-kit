- Rust axum Lambda API: login / me / logout / change password / user management.
- DynamoDB single-table account model, email uniqueness, GSI cursor listing.
- Immediate session revocation via `session_version`.
- CloudFront + S3 + Lambda Function URL (OAC) infrastructure.
- End-to-end deploy and smoke scripts.
- AI-first docs: `AI-PROMPT.md`, `AGENTS.md`, `docs/AI-USAGE.md`,
  `docs/EXTENDING-ADMIN-PAGES.md`.
