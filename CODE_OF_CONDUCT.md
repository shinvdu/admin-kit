# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussions technical. Harassment,
discrimination, and personal attacks are not welcome.

Report unacceptable behavior through GitHub’s report/abuse tools or by contacting
the maintainers privately. Maintainers may remove comments, close issues, or ban
participants who violate this code.
